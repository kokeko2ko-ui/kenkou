# DomoAI Chrome 自動生成

DomoAI の Web UI を Claude in Chrome でブラウザ操作し、ショットリスト（カットごとの
プロンプト）を一括で画像/動画生成する。API のリバースエンジニアリングは行わない
（DomoAI に既知の内部APIハックは無いため）— 実際の画面をクリック・入力して操作する。

## 前提条件

- **claude.ai / Claude Desktop + Claude in Chrome 拡張** が有効な環境専用。
  Claude Code（このリポジトリの CI やターミナル実行環境）にはブラウザ操作系 MCP が
  存在しないため、このスキルは実行できない。その場合は下記の
  [Claude Code 環境の場合](#claude-code-環境の場合) をユーザーに案内する。
- ユーザーが事前に https://www.domoai.app にログイン済みであること。
- 生成には DomoAI 側のクレジット（またはリラックスモード等の契約プラン）を使用する。
  本スキルはクレジット消費のバイパスは行わない。

## 入力: ショットリスト

ユーザーから「カットごとのプロンプト」のリストを受け取る。各カットについて
不明な点があれば確認する：

| 項目 | 内容 |
|---|---|
| プロンプト本文 | 英語推奨。日本語で渡された場合は軽く英訳して補う |
| 使用モデル | DomoAI（表情・アニメ調が得意）/ Seedance 2.0（ダイナミックな動き・実写・リップシンクが得意） |
| 解像度/品質 | まずは 720p や Fast 版でラフ生成 → OK なら本番解像度で再生成、という運用を推奨 |
| 参照画像 | キャラクターの3面図（正面・横・後ろ）や参照画像の有無 |

## 実行手順

### STEP 1: タブとログインを確認

```
mcp__Claude_in_Chrome__tabs_context_mcp (createIfEmpty: true)
```

`domoai.app` のタブがあれば使う。なければ新規タブで生成ページへ移動する
（画像生成: `https://www.domoai.app/en/create/gen`、動画生成はサイト内の
「Create」メニューから該当ツールへ）。

screenshot または DOM 読み取りでログイン状態を確認する。ログインしていない場合は
「DomoAI にログインしてください」と伝えて終了する。

### STEP 2: カットごとにループ

各カットについて以下を繰り返す：

1. モデル切り替えUIを操作し、指定モデル（DomoAI / Seedance 2.0）を選択する。
2. プロンプト入力欄をクリックし、既存テキストをクリアしてからカットのプロンプトを入力する。
3. 参照画像がある場合はアップロードする。Chrome 拡張がローカルファイル選択に対応していない
   場合は、ユーザーに手動アップロードを依頼する。
4. 解像度・尺などの生成オプションを設定する。
5. 生成ボタンをクリックする。
6. 生成完了まで待機する。進捗表示やサムネイルの変化を screenshot で
   20〜30秒間隔でポーリングし、完了を検知する。
7. 完了したらダウンロードボタンをクリックしてローカルにダウンロードする。
8. ダウンロードされたファイルをカット番号に応じてリネームし、ユーザーが指定した
   フォルダに整理する（保存先は事前にユーザーへ確認する）。
9. 次のカットに進む前に、生成結果（サムネイルやファイル名）を簡潔に報告する。

### STEP 3: 完了報告

全カット終了後、生成された全ファイルの一覧と保存先フォルダをまとめて報告する。

## コツ・注意点

- **破綻防止**: キャラクターの3面図（正面・横・後ろ）を参照画像として渡すと
  アングルが変わってもブレにくくなる。ユーザーがまだ用意していなければ先に作ることを提案する。
- **モデルの使い分け**: 表情重視のカットは DomoAI、ダイナミックな動き・実写・
  リップシンクは Seedance 2.0 が適している。
- **長尺の会話**: 一気に生成すると顔が崩れやすいため、短くカットごとに分割して
  生成し、後で編集ソフトで繋ぐことを提案する。
- **1カット1アクション**: 複数の動作（例:「歩きながら振り向く」）を同時に
  指示すると破綻しやすいので、プロンプトは単一の動作に絞る。
- **クレジット節約**: 本番前に低解像度/Fast版でラフ（当たり）を作り、OK な
  カットのみ高解像度で本番生成する。

## トラブルシューティング

| 問題 | 対処 |
|---|---|
| ログインしていない | ユーザーに https://www.domoai.app へのログインを依頼して終了 |
| 生成ボタンや入力欄が見つからない | ページのUIが変わっている可能性。screenshot で現在の画面を確認し、要素の位置をユーザーに確認する |
| クレジット不足 | ユーザーに残高・契約プラン（リラックスモード等）の確認を促す |
| 生成が失敗する | プロンプトを英語化・簡潔化して再試行する |
| ダウンロードが検出できない | ブラウザのダウンロード保存先設定を確認し、ユーザーに保存先を尋ねる |

## Claude Code 環境の場合

Chrome 操作系の MCP ツール（`mcp__Claude_in_Chrome__*`）が存在しないため、
このスキルはそのままでは実行できない。ユーザーには以下を伝える：

```
DomoAI のブラウザ自動化は、Claude in Chrome 拡張が有効な claude.ai または
Claude Desktop 環境で実行してください。Claude Code 環境では DomoAI の
画面を直接操作できません。
```
